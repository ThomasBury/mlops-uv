# M0. Contract and installable prototype

At noon, a reader asks whether Alex Silva or Robin Novak is more likely to win. Your program reports the probability for whichever player the reader names **first**. Before adding a model, make that rule executable and prove the command works on a machine that has the wheel installed.

## Decide what the forecast means

`F01` is a synthetic ATP singles fixture between Alex (`P01`) and Robin (`P02`), with a cutoff of `2030-06-10T12:00:00Z`. The probability is conditional on the match being played to completion. A published winner supplies the scoring label. With stable player order, Alex winning gives `1` and Robin winning gives `0`. Walkovers and retirements are excluded from scoring, and a fixture awaiting its result has no label yet.

Alex’s ranking was 30 at noon and corrected to 28 at 12:30 UTC. The noon forecast can use 30. The correction and the eventual winner both arrived after the cutoff. The prototype uses an illustrative constant so you can test the output contract by hand. Later checkpoints build features from cutoff-eligible history and use a two-day result delay as an explicit assumption for the 2021 archive.

Store the probability for the smaller stable ID (`P01`) and convert it to the requested order. With a probability of `0.70` for Alex, write down the expected result for `P02, P01` before running the script.

## Expose the ordering bug in a script

Use Bash, uv and Python 3.12. Work from a checkout of `course-v1-m0`, which is the first course checkpoint. To open it separately from your existing work, run the following from a repository that has the tag.

```bash
scratch="$(mktemp -d)"
git clone --branch course-v1-m0 --single-branch . "$scratch/source"
cd "$scratch/source"
```

If you are already in a checkout of the checkpoint, stay there. Run the remaining commands in one shell. Use a disposable directory for the script, wheel, and install.

```bash
work="$(mktemp -d)"
uv venv --python 3.12 "$work/installed"
cat > "$work/prototype.py" <<'PY'
from math import isclose


def requested_probability(first, second, canonical_probability):
    return canonical_probability


assert isclose(requested_probability("P02", "P01", 0.50), 0.50)
assert isclose(requested_probability("P01", "P02", 0.70), 0.70)
assert isclose(requested_probability("P02", "P01", 0.70), 0.30)
PY
"$work/installed/bin/python" "$work/prototype.py"
```

The last assertion should fail. The first assertion passed because `1 - 0.50` is also `0.50`. In the scratch script, add a branch for reversed order, then rerun it. All three assertions should pass. `isclose` allows for floating-point representation, so `1 - 0.70` can compare equal to `0.30` for this check.

Compare your change with [`probability_for_first_player`](../src/acebet/forecast.py). The package validates distinct, nonempty IDs and a probability in `[0, 1]` before applying the rule.


## Install the command from a wheel

In [`pyproject.toml`](../pyproject.toml), find the entry under `[project.scripts]`.

```toml
acebet-replay = "acebet.forecast:main"
```

`acebet.forecast` is the importable module and `main` is the function the installed command invokes. Build the wheel, install it into the fresh environment, and leave the checkout before running the command.

```bash
uv build --wheel --out-dir "$work/dist"
(
    cd "$work"
    unset PYTHONPATH PYTHONHOME
    uv pip install --python "$work/installed/bin/python" "$work"/dist/acebet-*.whl
    "$work/installed/bin/python" -I -c 'import acebet.forecast; print(acebet.forecast.__file__)'
    "$work/installed/bin/acebet-replay"
    "$work/installed/bin/acebet-replay" --canonical-probability 0.70
    "$work/installed/bin/acebet-replay" --canonical-probability 0.70 --reverse
)
```

Check that the import path is under `installed` in `site-packages`. All three JSON responses must identify `F01` and the same noon cutoff. Compare the ordered IDs and the reported probability.

| Invocation | `p1_id` | `p2_id` | `p1_win_probability` |
| --- | --- | --- | --- |
| Default | `P01` | `P02` | `0.50` |
| `--canonical-probability 0.70` | `P01` | `P02` | `0.70` |
| `--canonical-probability 0.70 --reverse` | `P02` | `P01` | `0.30` to floating-point precision |

The wheel carries the dependency requirements from `pyproject.toml`. Installing it directly resolves those requirements for the target environment. The earlier `uv run --locked` commands use the repository's exact versions. Keep the installed command, the three responses, and the unit contract as your evidence. Carry the stable order and cutoff rule into M1, where you will rebuild the match history from an identified source.
