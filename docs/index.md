# Start Here { .brand-title }

This ten-lesson tutorial is for Python users who have trained a model and want
to learn how to turn it into a reproducible service. You work with AceBet, a
tennis match predictor.

## What you’ll practice

- Recreate the Python environment, build model inputs, and compare models on
  matches played after the training period.
- Choose a saved model, serve an authenticated prediction, and verify which
  model answered.
- Diagnose requests using logs, metrics, and traces, then package the
  application and check that it runs in Docker and CI.

## Where to begin

- Begin with [lesson 1, Recreate the working environment](./tutorial/00-recreate-the-working-environment.md).
  The [tutorial overview](./tutorial/index.md) lists all ten lessons in order.
- Use the [packaged-model quickstart](./getting-started.md) to try a prediction
  with the model included in the checkout.
- Use the [companion guides](./guides/index.md) for more detail on training,
  model artifacts, and developer tools.
- Use the [reference](./reference/index.md) to look up API, CI, and deployment
  behavior.
